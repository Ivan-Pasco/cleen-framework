Auth Guards Demo

Role-based access control with protected endpoints

Public Endpoints

GET /api/public - No authentication required

Protected Endpoints (requires login)

GET /api/protected - Requires valid auth token

Admin Only

GET /api/admin/dashboard - Requires admin role
GET /api/admin/users/:id - Admin user management

Editor Only

GET /api/editor/posts - Requires editor role

Permission-Based

GET /api/posts/publish - Requires post.publish permission
